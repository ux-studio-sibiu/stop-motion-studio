# Nunito

The app's font, self-hosted (`src/styles/_fonts.scss`). One variable font file (weights 200-1000) per
character set: `latin`, `latin-ext` (Romanian: ă, â, î, ș, ț), `vietnamese`, `cyrillic`, `cyrillic-ext`.
They're the files Google Fonts serves for Nunito, taken from this project's own build (they were
downloaded by `next/font/google` until step 23).
